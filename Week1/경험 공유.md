# **😎실전 경험**

회사 프로젝트는 규모가 방대하고 외부에서 접근도 불가해, Claude CLI에 문제 상황을 설명하고 동일한 상황을 재현하는 테스트 환경을 만들어 학습했다.

**`claude.md`**

> Claude의 행동 규칙을 정의하는 파일
> 
- 파일 수정 시 **Perforce에서 checkout** 먼저 하도록 지시
- **엔진 경로**를 명시해두고, 답변의 근거를 항상 해당 경로 기준으로 가져오도록 설정

**`skill.md`**

> 특정 작업의 구현 형식/규칙을 정의하는 파일
> 
- 구현 시 갖춰야 할 **형식과 규칙**을 명세
- Claude가 관련 작업을 할 때 이 파일을 참고하도록 설정
